# Autoregressive Gaussian-process correction

`fortnum_multifidelity::autoregressive_gp_t` fits paired code outputs as
`high(x) = rho low(x) + delta(x)`. The correction delta has a zero-mean
squared-exponential Gaussian-process (GP) prior. This is a two-level instance
of [Kennedy and O'Hagan (2000)](https://doi.org/10.1093/biomet/87.1.1).
Chain separate instances for more levels. No input or output normalization is
implicit: use consistent scales, length scales and a covariance amplitude.

`fit(x, low, high, length, amplitude, rho, nugget, status)` takes training inputs
as `(n_input,n_train)` and paired outputs as `(n_output,n_train)`. The fixed
length vector, amplitude and rho are caller-selected hyperparameters. The
nugget is a standard deviation in output units; zero is permitted only when
Cholesky factorization succeeds. Invalid fits clear the trained state.

`predict(x, low, low_jac, value, jac, variance, status)` takes a new cheap-code
value and its Jacobian `(n_output,n_input)` and returns the corrected mean,
its Jacobian and the conditional correction variance. Outputs use independent
correction GPs with the same training covariance. `jvp` and `vjp` contract the
same analytical rows. Derivatives condition on the training set, fixed
hyperparameters and trained coefficients; they do not differentiate training
or the variance. Training and prediction covariance loops use OpenMP for more
than 128 training sites. Models own their arrays and concurrent predictions
are read-only.

The three scalar leaves and derivative rows are generated by FortSym.
`tools/codegen/check_generated.sh` regenerates them with the locked compiler
input. The CTest `multifidelity` checks a paired trigonometric code, a held-out
value, finite differences, the adjoint identity, zero correction and failed-fit
invalidation. This is a fixed-hyperparameter emulator, not hyperparameter
inference, an extrapolation certificate or a numerical error bound. Consumers
must validate on held-out exact evaluations and retain an exact final check.

`fortnum_gaussian_constraints` supplies two companion constructions.
`brownian_factor(time, initial_sd, drift_sd, factor, status)` returns a lower
factor for covariance `initial_sd**2 + drift_sd**2 * min(t_i-t_1,t_j-t_1)`.
Times must be finite and strictly increasing; standard deviations are finite
and nonnegative. Each column is an independent standard normal coordinate.

`constrain_discrepancy(chol, protected, basis, constrained, status)` removes
from each basis column its projection onto the span of the protected columns
in the metric defined by the supplied lower covariance factor. Singular value
decomposition handles dependent columns. This protects a fixed tangent space;
it does not imply global identifiability of a nonlinear model. The CTest
`gaussian_constraints` checks Brownian covariances, rejection of unsorted times,
and nontrivial orthogonality with correlated noise and a rank-deficient span.
